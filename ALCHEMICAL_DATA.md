# Alchemical Correspondence System — Complete Data

## System Overview

The complete alchemical system comprises:
- **4 Elements** — Fire, Water, Air, Earth (fundamental)
- **7 Planets & Metals** — Sun/Gold, Moon/Silver, Mercury/Mercury, Venus/Copper, Mars/Iron, Jupiter/Tin, Saturn/Lead
- **12 Zodiacal Processes** — Aries (Calcination) through Pisces (Dissolution)
- **3 Paracelsian Principles** — Sulfur (combustibility), Salt (fixation), Mercury (volatility)

Total: **26 primary block types** × **3 principle modifiers** = 78 potential variations

## THREE PARACELSIAN PRINCIPLES (As Block Modifiers)

Each block can be modified by one of three principles, changing its behavior:

### 1. **Sulfur** (Hot, Dry) — Soul/Combustibility
- **Visual:** Red aura, flames, aggressive energy
- **Effect on Reactions:** +50% heat/fire effects, accelerated reactions
- **Block Behavior:** Moves faster, hits harder
- **XP Gain:** +1 for any reaction with Sulfur block
- **Pairing Examples:**
  - Sulfur-Fire: Wildfire (uncontrolled)
  - Sulfur-Water: Explosive steam (violent reaction)
  - Sulfur-Air: Volatile explosion (chain reactions)

### 2. **Salt** (Cold, Wet) — Body/Fixation
- **Visual:** White crystalline, stable, grounding
- **Effect on Reactions:** +50% fixation/stasis effects, slows progression
- **Block Behavior:** Moves slower, resists destruction
- **XP Gain:** +1 for reactions that overcome Salt blocks
- **Pairing Examples:**
  - Salt-Water: Crystallization (solid salt)
  - Salt-Earth: Petrification (hardening)
  - Salt-Fire: Calcination through struggle

### 3. **Mercury** (Neutral) — Spirit/Volatility
- **Visual:** Green shimmer, quicksilver, transformative
- **Effect on Reactions:** Unpredictable, random secondary effects
- **Block Behavior:** Erratic movement, teleportation
- **XP Gain:** +2 for discovering new Mercury-based reactions
- **Pairing Examples:**
  - Mercury-Air: Sublimation (ethereal)
  - Mercury-Fire: Volatile transformation
  - Mercury-Water: Amalgamation (true mixing)

## CASCADING EFFECTS FRAMEWORK

Each reaction can trigger **secondary** and **tertiary** effects:

### Level 1: Primary Reaction
Two blocks meet → reaction occurs → description unlocked

### Level 2: Secondary Effect
Result of primary reaction → creates field effect or spawns new entity

Examples:
- Steam cloud blocks view, affects nearby blocks
- Ash particles trigger dust reactions with air blocks
- Wildfire spreads to adjacent fire elements
- Mud solidifies, creating obstacles

### Level 3: Tertiary Effect
Secondary effects combine → unlock advanced knowledge

Examples:
- Steam (fire+water) + air block = mist circulation (new property)
- Ash (fire+earth) + mercury principle = ash transmutation
- Multiple cascades = "chain reaction mastery" (unlock new ability)
